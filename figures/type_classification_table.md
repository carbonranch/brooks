# Call types: formal classification (v3)

Rules: form = plane clustered on (song form from each singer's audio); tick = trill with R25 <= 25 Hz; glide = median centroid change onset to end as % of carrier, flat if |glide| < 1.0 %; hooked = a falling glide whose mid-pulse centroid sits more than 0.4 % of the carrier below the chord (bend_pct < -0.4); syllables per chirp = chirp duty / chirp rate x syllable rate. Descriptors are medians over the type's fine folds (n_folds random windows of singer-nights near 25 C; T_sample = their median night temperature).
